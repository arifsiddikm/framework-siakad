# Brand SiakadKu

| File | Pakai untuk |
|---|---|
| `siakadku-logo.svg` / `.png` | Logo utama, latar terang |
| `siakadku-logo-white.svg` / `.png` | Logo di atas navy (sidebar, login, footer) |
| `siakadku-mark.svg` | Lambang saja (avatar, kop PDF) |
| `favicon.svg`, `favicon.ico`, `favicon-16/32/48.png` | Tab browser |
| `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `site.webmanifest` | PWA / layar utama HP |
| `tokens.css` | Token warna + font untuk Tailwind v4 (`@theme`) |
| `logo-sheet.png` | Ringkasan visual semua varian |

Lambang: huruf **S** dari dua siku (bracket) navy dengan satu balok amber di tengah. Balok amber adalah satu-satunya
pemakaian amber sebagai dekorasi.

Aturan: jarak bebas minimal setinggi balok amber di sekeliling lambang; ukuran minimum logo penuh 120 px, lambang 16 px;
jangan beri bayangan, gradasi, atau warna lain.

Logo ini **contoh/placeholder** untuk demo. Ganti sebelum produksi bila perlu aset final dari desainer.

Font (SIL OFL 1.1, di-host sendiri — tanpa CDN): IBM Plex Sans, IBM Plex Mono, Source Serif 4. Lisensi ada di `design/fonts/`.
